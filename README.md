# اختبر معلوماتك العسكرية (فوج الحماية)

منصة اختبارات عربية متجاوبة تشمل الاختبارات العشوائية، التصحيح الفوري، مراجعة الأخطاء، لوحة إدارة الأسئلة، وحفظ نتائج المتدربين عبر Supabase.

**تصميم وإعداد: محمود عبد المعطي الأحمد**

## التشغيل

1. شغّل `supabase/setup.sql` داخل Supabase SQL Editor.
2. أنشئ مستخدمًا في Supabase Auth وأضف UUID إلى جدول `admin_users`.
3. ضع `SUPABASE_URL` و`SUPABASE_ANON_KEY` في `js/config.js`.
4. ارفع الملفات إلى GitHub وفعل GitHub Pages من الفرع `main` والمجلد `/ (root)`.

التعليمات العربية الكاملة موجودة في [`README_AR.txt`](README_AR.txt).

## ملاحظة

المحتوى الافتراضي عبارة عن نماذج تعليمية عامة وآمنة. تُدار الأسئلة الفعلية من لوحة المدير.
